### 4.2 macOS（未构建）

宿主不是 macOS，且未提供 Developer ID 签名与 notarization 凭据；`npm run build:mac` 的前置检查按预期阻止构建。Universal DMG/ZIP 均不存在，`verify-release` 对 mac 平台的强制签名/公证门槛无法满足。

### 4.3 Linux（未产出正式产物）

Windows 宿主上：DEB 构建因缺少 `fpm` 失败（ENOENT），AppImage 构建因符号链接权限失败（EPERM）；正式构建需 Linux runner（CI 中已安装 fpm 与 libfuse2）。仓库 `release/` 下存在 `linux-unpacked` 目录（解包形态，非发布产物），不含 `.deb` 与 `.AppImage`。

### 4.4 CI 打包工作流（未运行）

`.github/workflows/package.yml`（名称 `Cross-platform packages`，仅手动触发）包含 checks、windows、macos、linux、aggregate 五个 job；尚未在 GitHub 上运行。运行前需配置 secrets：`CSC_LINK`、`CSC_KEY_PASSWORD`、`APPLE_ID`、`APPLE_APP_SPECIFIC_PASSWORD`、`APPLE_TEAM_ID`、`UNI_SHELL_LINUX_MAINTAINER`。缺少签名 secrets 时 workflow 应失败，不得产出未签名正式包。
